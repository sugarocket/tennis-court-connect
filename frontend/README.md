# 🎨 Frontend

This is where the web/mobile UI lives.

## Recommended Stack
- Next.js 14+ (App Router)
- Tailwind CSS
- shadcn/ui components
- Supabase JS client
- Leaflet for maps

## Quick Start (when ready)
```bash
npx create-next-app@latest . --yes
npm install @supabase/supabase-js leaflet lucide-react
```

## Folder Ideas
- `app/` — pages/routes
- `components/` — UI components
- `lib/` — Supabase client, utils
- `hooks/` — custom React hooks
- `types/` — TypeScript types (or import from `../shared`)

> See root README and `docs/architecture/overview.md` for more.
