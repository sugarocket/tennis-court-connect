# 🎾 TennisCourtConnect

> **Vibe-coded tennis platform** — Court booking, UTR-style matchmaking, leagues, events, and real-time court status updates.

## 🚀 Getting Started

1. **Clone / pull this repo**
2. **Pick your stack** — See [docs/architecture/overview.md](docs/architecture/overview.md)
3. **Install deps** — `cd frontend && npm install` (or your stack)
4. **Run locally** — `npm run dev`
5. **Start vibe-coding** — Follow the PRD in `docs/specs/`

## ✨ Core Features

| Feature | Description |
|--------|-------------|
| 🏟️ Court Booking | Public + club courts, live status, reservations |
| 📚 Courses & Sessions | Coaches post clinics/lessons, players sign up |
| 🏆 UTR Matchmaking | Skill-based player matching, leagues, tournaments |
| 👥 Casual Finder | "Looking for a game" posts, nearby alerts |
| 📅 Events | Social mixers, competitive tournaments, RSVP |
| 📍 Real-time Status | Crowdsourced court availability updates |
